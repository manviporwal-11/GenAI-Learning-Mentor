# 🎓 GenAI Learning Mentor

An AI-powered personalized learning mentor that guides students using **Retrieval-Augmented Generation (RAG)**. Instead of generic answers, it retrieves relevant content and generates responses that are accurate and grounded.

## ✨ Features
- 🧠 **RAG Pipeline**: semantic search with FAISS, answers generated through LangChain
- 🎯 **Personalized Guidance**: tailored learning support for each student
- 🔐 **User Accounts**: login and registration
- 📊 **Dashboard**: a simple interface to interact with the mentor

## 🛠️ Tech Stack
| Layer | Technology |
|-------|------------|
| Language | Python |
| RAG Framework | LangChain |
| Vector Store | FAISS |
| Frontend | Streamlit, HTML, CSS, JavaScript |

## 🚀 Getting Started

1. Clone the repository
```bash
git clone https://github.com/manviporwal-11/GenAI-Learning-Mentor.git
cd GenAI-Learning-Mentor
```

2. Create a virtual environment
```bash
python -m venv venv
venv\Scripts\activate
```

3. Add your API key in a `.env` file

4. Run the app
```bash
streamlit run app.py
```
